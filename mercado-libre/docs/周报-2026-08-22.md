# 美客多多店铺数据看板 · 项目周报

> 汇报周期：2026-08-17 ~ 08-22（本周）
> 项目目标：搭建多店铺经营数据看板 + 飞书自动同步，统一查看销量/库存/广告数据

---

## 一、本周综述

本周完成了美客多多店铺数据看板的**设计、开发、调试与交付**。目前系统已覆盖 **2 个店铺、53 个商品**，数据每天自动更新到飞书表格，**经校验 0 缺失 / 0 多余 / 0 值差**，后续添加店铺数据再次调试和测试数据。

---

## 二、本周核心成果

1. **多店铺数据看板上线**：经营总览、商品分析、广告流量统一查看（销量、库存、ROAS、自然/付费流量等全指标）
2. **飞书多维表格自动同步上线**：按「店铺×月份」自动分表，**每天 3 个时间点自动更新**，打开飞书即看最新数据
3. **广告数据定档机制**：广告数据次日定档，定档前明确标记，**杜绝数据误导**
4. **数据准确性专项**：解决 7 个实际问题（见第五节），数据质量达到 **0 缺失 / 0 多余 / 0 值差**
5. **历史库存可追溯**：从本周起每天记录库存/价格快照（官方不提供历史库存，只能自己积累）
6. **文档交付**：架构、数据口径、部署运维、变更记录全套文档齐备

## 五、本周问题处理（发现问题 → 处理 → 结果）

| 问题 | 处理 | 结果 |
|---|---|---|
| 销量与后台对不上（后台 8 单 vs 表 7 单） | 逐单核对，定位为 1 单已取消；修正统计口径，只计已付款订单 | 13 个取消订单全部正确排除，与后台一致 ✅ |
| 每次同步重复写入全部数据，浪费时间 | 改为增量同步：只更新有变化的行 | 重复同步写入量降为 0 ✅ |
| 历史数据被反复重写、时间戳混乱 | 改为历史冻结：只同步最近 2 天 | 时间戳稳定、同步量极小 ✅ |
| 历史库存"不可知"（官方不提供） | 从本周起每日快照；未记录的日子明确显示"未知" | 诚实反映，不误导 ✅ |
| 定时任务"没触发"（北京 13:50） | 排查确认为**接口限流**（429），非定时故障 | 增加自动重试，已手动补跑 ✅ |
