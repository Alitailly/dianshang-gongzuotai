# 商品分析表格设计 — 阶段性结论（待定稿）

> 状态：已讨论出核心方案，细节待拍板。2026-08 记录。

## 核心目标

让老板/运营看一行数据就能回答三个问题：

1. 商品质量过关吗？（该不该重点推）
2. 广告值不值得加投？（花钱对不对）
3. 最后还剩多少钱？（平台净得）

## 数据关系（先理清）

- **销量结构**：总销量 = 自然销量 + 广告销量
  - 广告销量(件) ≈ 广告销售额 × 总销量 ÷ 总销售额（用实际成交均价推断，ML 无广告件数接口）
  - 自然销量(件) = 总销量 − 广告销量
- **广告投入产出**：广告花费 → 广告销售额 → ROAS / ACOS
- **扣款链**：商品销售价 − 平台佣金 − 物流费 − 广告花费 = 平台净得

## 表格设计（四段"决策链"）

| 段 | 列 | 决策目的 |
|---|---|---|
| ① 质量诊断 | 体验分 / 商品评分 / 转化率 / 🟢质量状态 | 过关吗 |
| ② 销量结构 | 总销量 / 自然销量 / 广告销量 / 广告销量占比 + 迷你堆叠条 | 自然卖得动吗 |
| ③ 广告投入产出 | 广告花费 / 广告销售额 / ROAS / ACOS / 广告花费占比 / 🟢广告决策 | 值不值加投 |
| ④ 扣款链→净得 | 销售价 / 佣金 / 物流 / 广告 / 💰平台净得 | 还剩多少 |

## 让关系直观的手法

1. 两个**结论列**（质量状态 + 广告决策）：数字翻译成 🟢🟡🔴 决策语言。
2. **迷你堆叠条**：自然销售额 vs 广告销售额占比一眼可见。
3. **条件标色**：ROAS 低于盈亏线、净得为负、质量不过关 → 自动标红。
