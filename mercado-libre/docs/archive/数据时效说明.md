# 数据时效说明（重要）

美客多（巴西站 MLB）各数据源更新时效不同：**唯一有延时的是广告（T+1，次日巴西 10:00 定档）**；
其余数据（商品/订单/库存/体验分）实时；**访客**按天去重、查询恒截断到巴西昨天。

## 核心规则：广告数据 T+1，次日 10:00（巴西时间）定档

- ML 广告后台**实时可见**当天数据，但**正式定档在次日 10:00（巴西时间 UTC-3）**；定档前数据不完整，不可作为最终口径。
- 看板**广告列只统计到定档截止日**，未定档日不计入：

| 当前巴西时间 | 广告定档截止日 |
|---|---|
| 10:00 之前 | **前天**（今天、昨天广告都未定档） |
| 10:00 之后（含） | **昨天**（今天未定档） |

- 实现：`src/timeutil.py` → `br_latest_finalized_date()`（`AD_FINALIZE_HOUR = 10`）；
  接口 `GET /api/meta/data-status` 返回 `br_today`（可查至今天）、`latest_finalized_date`（广告定档截止日）、`earliest_date`（快照最早一天）。

## 各数据源时效一览

| 数据 | 时效 | 来源 |
|---|---|---|
| 商品标题/价格/可售库存 | ✅ 实时 | `/items/{id}` |
| 订单（已售/销售金额/佣金/物流费） | ✅ 实时 | `/orders/search` + `/shipments/{id}/costs` |
| 访客（全流量总访问） | ⚠️ 按天去重 | `/items/{id}/visits`（=后台 Visitas únicas；**查询恒截断到巴西昨天**，今天数据不完整；无含重复点击的总访客口径） |
| 体验分 | ⚠️ 按天更新 | `/item/{id}/performance` |
| 广告（花费/点击/曝光/销售额/ROAS/ACOS） | ❌ T+1 | 广告 API，**只统计到定档截止日** |

## 看板口径

- **日期选择器**：预设「近N天」= **最近 N 个完整日（截止巴西昨天，不含今天）**；**自定义区间**可查至巴西今天（广告列仍按定档日统计+提示）。
- **广告列**：只统计到定档截止日；所选范围含未定档日时页面提示「所选范围含未定档日，广告未计入」。
- **全流量总访问** = 商品 visits 接口 `total_visits`（按天去重独立访客，恒截断到巴西昨天）= 自然 + 广告全部详情访问。
- **自然访问(估算)** = 全流量总访问 − 广告点击（广告 API 无"Total de visitas"字段，用广告点击近似，标注偏差；10:00 前缺昨天 → 略偏高，10:00 后一致）。
- **已售** = 区间内已支付订单聚合；**可售库存** = `/items/{id}` 当前可售量。
- **商品分析页当前组**：商品信息 / 库存 / 流量·自然vs付费 / 广告·加投决策 / 质量（收支·盈利组已按用户要求移除）。

## 日常注意

- 每天 **10:00 巴西时间（= 21:00 北京时间，巴西夏令时期间为 22:00）** 之后，昨天的广告才定档，广告定档截止日自动前移一天。
- 要看最新（含今天）的销量/销售，需先**同步数据**；同步完成后自动清空访客缓存。
- 若某天在 10:00 前同步，快照里当天广告是未定档值；广告列按定档截止日统计，不会显示这些未定档值。
