# 看板全模块数据设计（仿蓝鲸BI · 全部可调用数据）

> 定位：**设计文档**，不改动已实现部分（经营总览 / 商品分析 v1 保持现状）。
> 目标：把蓝鲸 BI 面板的每个模块，对应到我们能从 ML API 拿到的全部数据，逐模块写清楚
> 「面板长什么样 / 数据从哪个接口来 / 哪些已有 / 哪些要新增 / 哪些必须手工」。
> 数据跨模块重复出现属正常（如销量在多个模块都出现），本设计**不考虑去重**。
> 标注：✅=已有采集 ｜ 🆕=需新增采集 ｜ ⚠️=接口路径需实测确认 ｜ ✋=ML 给不了（手工/本地积累）

## 1. 经营总览（#/index）— ✅ 已有 v1，设计参考

- 时间范围：今天/昨天/近7/30/60/90天/自定义（已有）。
- KPI 卡片：总销售额(+环比+昨日) / 总销量 / 退款数量 / 访问量 / 昨日动销率。
  - 退款数量：🆕 需从订单/退货数据统计（当前未采集）。
  - 动销率：有销量 listing ÷ 在售 listing（daily_snapshot + product_variation 可算）。
- 店铺表现 tab：每店 订单/访问量/转化率 + 表（序号|店铺|销售额|订单数|访问量|转化率）。
  - 订单数：🆕 daily_snapshot 加 order_count（已有订单数据，加个 COUNT 即可）。
  - 转化率 = 订单数 ÷ 访问量。
- 库存信息（周转天数/急需补货/在售库存数量）：✋ 周转/补货需手工配置 + 本地积累；在售库存 ✅（available_quantity）。
- 预警信息 / 消息通知：🆕 差评(评价)、店铺声誉、索赔、售前/售后消息采集后才有。
- 排行榜 tab（销量暴涨/暴跌、退货骤增、访问暴跌、滞销）：✅ 销量/销售额/广告/访问均可从现有数据算；退货需 🆕。

## 3. 交易分析

### 3.1 即时分析（#/tradeAnalyze/realtimeAnalyze）
- 面板：实时销售/订单动态（蓝鲸按小时看当日走势）。
- 数据源：🆕 `GET /orders/search`（当日，实时）→ 小时聚合；`GET /orders/{id}` 明细。
- 状态：订单采集 ✅（按天），按「小时」粒度需新增聚合逻辑。

### 3.2 历史分析（#/tradeAnalyze/productAnalyze）
- 面板：按商品的历史销售/流量趋势（蓝鲸：近N天销量/访问曲线 + 表）。
- 数据源：✅ 本地每日快照（daily_snapshot 按天累积，ML 不给历史）；访客趋势 🆕 需开始按天存访客（当前访客是按需实时查，不做按天——成本高，4770 次/90天）。
- 备注：从接入日开始积累，越久越全。

### 3.3 广告流量（#/tradeAnalyze/advertise）★ 数据已有
- KPI 卡：销售额 / 广告花费 / 广告税 / 曝光 / 点击 / 订单数 / ROAS / ACOS / ACoAS / CPC / 点击率 / 自然销量 / 自然销售额 / 自然占比 / 广告占比（全部带环比）。
  - ✅ 已有：销售额、广告花费、曝光、点击、ROAS、ACOS（来自 product_ads metrics）。
  - 🆕 需新增：广告税 advertTax、订单数、ACoAS、CPC、点击率、自然/广告拆分（ML 无直接接口，需本地规则拆分——如：广告点击≥1 的订单算广告单）。
- 趋势图：🆕 按天曝光/点击/花费曲线（daily_snapshot 已有按天广告数据，直接可画）。
- 商品广告列表（padsList）：✅ ads/search 分页列表（商品维度）。
- 接口：`GET /advertising/advertisers` + `GET /marketplace/advertising/{site}/advertisers/{adv}/product_ads/ads/search?metrics=clicks,prints,ctr,cost,roas,total_amount,acos`（Api-Version:2，T+1 次日10:00定档）。

### 3.4 利润分析（#/tradeAnalyze/historyAnalyze）★ 蓝鲸核心
- 面板：店铺 | 商品状态 | 销售(BRL) | 利润(BRL) | 平台费用(BRL) | 采购成本(BRL) | 头程物流(BRL) | 其他成本(BRL) | 商品信息。
- 利润公式（蓝鲸）：销售 − 平台佣金 − 广告费 − 采购成本 − 头程物流 − 配送费 − 其他成本 − 退款 − 税。
- 数据源：
  - ✅ 销售、平台佣金（订单 sale_fee）、广告费、配送费（shipments costs）、退款金额(🆕 订单退款)。
  - ✋ 采购成本 / 头程物流 / 其他成本：手工录入（配置→成本管理），本地 cost 表。
  - ✋ 税率 IVA：巴西 17% 左右，可配置固定值。
- 状态：毛利(销售−佣金−广告−物流) ✅ 可算；净利 ✋ 等成本录入。

## 7. 库存管理（#/stock）
- 表头：库存趋势 | 商品名称 | 商品ID/SKU | ML code | 规格 | 尺寸 | 店铺 | 状态 | 库存类型 | 日均销量(手动) | 日均销量 | 近7/15/30/60天销量 | 可售天数 | 月结余库存 | 总库存 | 在库金额(RMB) | 可用库存 | 不可用库存 | 转移中库存 | 在途库存 | 在途金额 | 自定义库存 | 促销预留 | 补货周期(天) | 安全库存系数 | 预警天数 | 补货建议 | 补货数量 | 备注 | 图片。
