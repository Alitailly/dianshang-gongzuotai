# 04 — 消息工作台：后端核心

**What to build:** 站内信工作台的后端全链路——① 消息接入层（拉取消息会话、拉取会话内消息、发送回复；注意新消息架构：MLB/MLC 收件人用国家 agent ID）② 待审队列（SQLite 持久化，状态机：新消息→草稿→已发送/已跳过）③ 草稿生成（按消息售前/售后 tag 分流：售前以商品信息为上下文、售后查订单/物流；上下文取会话内完整消息历史）④ API（列消息/生成草稿/确认发送/跳过）。发送永远需人工确认，系统不自动发送。
