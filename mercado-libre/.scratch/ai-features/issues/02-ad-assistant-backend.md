# 02 — 广告助手：后端出建议

**What to build:** 广告助手的后端分析接口——选定店铺 + 时间范围 → 复用现有广告聚合查询 → 组装 prompt（含指标定义与定档语义）→ 调 LLM → 返回结构化建议（表现总览 + 3~5 条建议，每条含问题/数据依据/建议行动）。无数据时返回清晰提示而非报错。

**Blocked by:** 01 — LLM 底座 + 测试地基

- [x] prompt 包含所选店铺/时间范围的广告聚合数据
- [x] 所选范围无数据时返回明确提示（不是崩溃/空结果）
- [x] 接缝 ② 测试：fake LLM + 数据查询下，输出结构与 prompt 内容验证通过
